## ?? 核心概念速查表

### ConfigComponent（配置组件）
```csharp
// 获取配置（类型安全）
var config = m_ConfigComponent.GetConfig<TbItemConfig>();

// 检查配置是否存在
bool exists = m_ConfigComponent.HasConfig<TbItemConfig>();

// 添加配置
m_ConfigComponent.Add("TbItemConfig", config);

// 移除配置
m_ConfigComponent.RemoveConfig<TbItemConfig>();

// 清空所有
m_ConfigComponent.RemoveAllConfigs();
```

### 查询模式
```csharp
// 模式 1：单条查询
config.TryGet(1001, out var item);

// 模式 2：全部查询
var allItems = config.GetAll();

// 模式 3：条件查询
var filtered = config.GetAll().Where(x => x.Price > 100);

// 模式 4：批量查询
var results = new List<ItemConfig>();
foreach (var id in ids)
{
    if (config.TryGet(id, out var item))
        results.Add(item);
}
```

### 配置访问的正确方式
```csharp
// ? 每次使用前重新获取（支持热更新）
public void UseConfig()
{
    var config = m_ConfigComponent.GetConfig<TbItemConfig>();
    if (config != null && config.TryGet(1001, out var item))
    {
        // 使用
    }
}

// ? 不要缓存配置对象（热更新后会过期）
private TbItemConfig m_CachedConfig;  // 危险！
```

### 性能要点
```csharp
// ? 好：获取一次，多次使用
var config = m_ConfigComponent.GetConfig<TbItemConfig>();
for (int i = 0; i < 1000; i++)
{
    config.TryGet(i, out _);
}

// ? 坏：循环中重复获取
for (int i = 0; i < 1000; i++)
{
    var config = m_ConfigComponent.GetConfig<TbItemConfig>();  // 重复
    config.TryGet(i, out _);
}
```
